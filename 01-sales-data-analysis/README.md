# Project 01: Sales Performance Analysis

## Project Overview

This project investigates e-commerce sales performance using SQL and Python. The objective is to transform transactional data into meaningful business insights.

## Business Questions

1. What is the total sales revenue?
2. Which products and categories generate the highest revenue?
3. Which regions contribute most to sales?
4. How does revenue change over time?
5. What recommendations can be made from the findings?

## Dataset

Source: Global E-Commerce Sales & Customer Data, Kaggle.

The dataset contains 2,000 sales records, including order dates, customer segments, products, quantities, prices and geographic information.
