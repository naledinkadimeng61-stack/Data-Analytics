# Data-Analytics

A collection of practical projects demonstrating data analytics, business intelligence and data engineering skills, with applications in business and industrial operations.

## About

This portfolio documents my development as a data professional, building on an academic foundation in Chemical Engineering and practical exposure to technical and operational environments.

The projects focus on using data to understand performance, identify patterns, investigate problems and support evidence-based decisions.

## Technical Toolkit

- **SQL:** querying, filtering, joins, aggregation and data quality checks
- **Python:** programming, data manipulation and analysis with pandas
- **Excel:** data preparation, analysis and reporting
- **Power BI:** data modelling, measures and interactive dashboards
- **Data Engineering:** data extraction, transformation and loading (ETL)

## How Projects Are Presented

Each completed project aims to include:
- A clearly defined business problem and analysis objectives
- Dataset source, scope and data dictionary
- Data quality assessment and preparation
- Reproducible code, SQL queries or notebooks
- Findings supported by calculations and visualisations
- Practical recommendations and limitations

## Data Ethics

Projects use public or appropriately simulated datasets. Confidential employer, customer and operational information is not included.
